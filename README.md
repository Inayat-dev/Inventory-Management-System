# 📦 Inventory Management System

A simple Inventory Management System built to manage products, stock, and basic operations efficiently.

---

## 🚀 Getting Started

To run the project locally, follow these steps:

### ▶️ Start the Application

* Double-click the **`start.bat`** file
  **OR**
* Run in terminal:

  ```bash
  start.bat
  ```

This will automatically start the system on your local machine.
